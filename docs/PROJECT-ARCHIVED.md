# Shadowframe AI — Project Archived

**Status: archived.** Shadowframe AI is no longer under active development.

This notice is the final project update. There will be no future feature work,
model-pack refreshes, compatibility updates, security fixes, installer rebuilds,
or user support for Shadowframe AI.

The repository and its published release files are retained for reference and
for existing users who want to keep running a previously released build. They
are provided as-is, without any promise that they will work with future
Windows, GPU drivers, Python versions, ComfyUI versions, model files, or
third-party services.

## Existing users

- Keep a copy of the installer and model files that currently work for you.
- Do not expect the Hugging Face model bundles, GitHub releases, or external
  model hosts to remain available indefinitely.
- Keep your own backups of generated media, prompts, workflows, and local
  configuration.
- Treat bridge addresses, access keys, and local runtime credentials as
  private; do not publish them in issues or repository uploads.

## Licensing and model files

Shadowframe source and documentation are separate from the third-party model,
LoRA, VAE, encoder, and custom-node files used by local installations. Their
licenses and availability are controlled by their respective authors and
hosts. Review those terms before redistributing or repackaging any files.

## Final support boundary

Issues, pull requests, support requests, and compatibility reports may remain
visible for historical context, but they should not be treated as an active
support channel. This project is closed.
