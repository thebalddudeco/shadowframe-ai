# Final Shadowframe AI Release Notes

## Project closure

Shadowframe AI has reached its final public state and is now archived. This is
the last maintenance update. No future releases, patches, model updates, or
support commitments are planned.

## What remains available

- The public-release source and documentation in this repository.
- The published GitHub release history, including the one-file Windows setup
  flow documented by the latest public release.
- Existing Hugging Face model-pack artifacts where they remain available from
  their original publication.
- The separate private/local distro used by the creator, which is not part of
  this public repository and is not supported by this archive notice.

## Important limitations

The archived build depends on a local Windows GPU environment, the bundled or
installed ComfyUI runtime, third-party model files, and external services that
may change or disappear. A successful installation in the past does not imply
that a clean installation will succeed on a future machine.

Generated files, prompts, workflows, model files, and local credentials remain
the user's responsibility. Back them up before changing or removing an
installation.

## Final statement

Shadowframe AI is provided as a historical, self-hosted project. Use the
existing releases at your own discretion; there is no future support channel.
